# 🌐 PUESC e-TOLL & SENT Web Hub

Интерактивный веб-интерфейс для управления устройствами в государственной системе **PUESC (Польша)** для проектов **e-TOLL** и **SENT**.

---

## 🚀 Возможности
- 📝 **Выбор контрагента:** Быстрое указание заказчика (`MotoGuard`, `Overseer`, `ТрансЛогистик` и т.д.).
- 📁 **Удобная загрузка:** Drag-and-Drop `.txt` / `.csv` файлов или вставка списка IMEI из буфера.
- ⚙ **Гибкое управление галками:**
  - Отдельные чекбоксы `e-TOLL` и `SENT` для каждого IMEI.
  - Массовые кнопки: **«Выбрать ВСЁ»**, **«Снять ВСЁ»**, **«Только e-TOLL»**, **«Только SENT»**.
- 🚀 **Регистрация в PUESC:** Отправка `ZSL_120`, авто-получение `ZSL_121` и авто-дозапрос действующих реквизитов для ранее добавленных устройств (`ZSL_122`).
- 🗑 **Удаление устройств:** Пакетное удаление `GPSDeviceToRemove` с контролем статусов.
- 📊 **Экспорт отчетов:** Скачивание отчетов в форматах **TXT**, **CSV** и **XML** с нумерацией `dd.mm.yyyy_<tag>_<N>`.

---

## 💻 Локальный запуск (1 команда)

```bash
cd web_app
python3 server.py
```
Откройте в браузере: **`http://localhost:8000`**

---

## ☁ Бесплатный деплой в облако (Render.com)

1. Загрузите репозиторий на **GitHub** (или создайте отдельный репозиторий для папки `web_app`).
2. Перейдите на [render.com](https://render.com) и войдите через GitHub.
3. Нажмите **New +** -> **Web Service**.
4. Выберите ваш репозиторий.
5. Укажите:
   - **Environment:** `Python`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python server.py`
   - **Plan:** `Free`
6. Нажмите **Deploy Web Service** — через 1–2 минуты ваш сервис будет доступен по бесплатному публичному адресу `https://ваш-сервис.onrender.com`!
